❯ 百度收录 / 新手站长问：网站怎么被百度收录？从注册域名到提交资源平台的完整步骤

网站被百度收录，是一个可以手动干预的流程，完整链条是：注册域名 → 配置 DNS 解析 → 部署网站 → 等待 HTTPS 生效 → 在百度搜索资源平台验证站点 → 提交 sitemap → 等待爬虫抓取。本文基于 jiyou.site 的真实部署过程，记录每一步的具体做法和踩过的坑，供同样从零开始的新手站长参考。

网站被百度收录要经过哪几个环节？

网站被百度收录要经过六个环节，分别是注册域名、配置域名解析、部署可访问的网站、在百度搜索资源平台添加并验证站点、提交站点地图（sitemap），以及等待百度爬虫抓取收录。其中前三个环节决定"网站能不能被访问"，后三个环节决定"百度能不能发现你"，任何一环出问题都会导致收录失败。

很多新手以为"网站做好上线就能被百度收录"，实际上百度每天要抓取海量新网址，如果不主动提交，新网站被发现可能需要数周甚至数月。主动提交不能保证收录，但能显著缩短被发现的时间。下面按顺序说明每个环节。

注册域名时要注意什么？

注册域名时要注意两点：一是选择支持实名认证的注册商，二是域名主体信息要与后续备案或平台验证保持一致。域名是网站的唯一地址，也是 AI 引擎识别内容来源的实体标识，建议用真实身份注册 .com/.cn/.site 等主流后缀。

本次案例在阿里云注册了 jiyou.site，年费约几十元。中国内地注册域名必须完成实名认证，未实名的域名会无法解析。实名认证通常在注册后 1-2 天内审核完成，提交后耐心等待即可，这一步不完成，后面的 DNS 解析和网站访问都会受影响。

域名解析怎么配置才能访问网站？

域名解析配置要分两条记录：主域名（@）用 A 记录指向网站托管商的服务器 IP，www 子域名用 CNAME 记录指向托管商提供的域名别名。以 GitHub Pages 为例，四条 A 记录的 IP 是 185.199.108.153、185.199.109.153、185.199.110.153、185.199.111.153，CNAME 记录指向你的 GitHub 用户名.github.io。

配置时最容易踩的坑是 CNAME 冲突：如果 www 子域名下已经存在 A 记录，再添加 CNAME 记录会被 DNS 平台拒绝，提示"解析记录有冲突"。解决办法是先删除 www 下已有的 A 记录，再添加 CNAME。另外，GitHub Pages 还需要在仓库设置里把自定义域名填成 www.jiyou.site，并在仓库根目录放一个内容为 www.jiyou.site 的 CNAME 文件——只在 DNS 里配置是不够的，两端必须一致。

配置完成后可以立即用命令行验证 DNS 是否生效：执行 ping www.jiyou.site，如果返回 GitHub 的 IP 地址，说明解析已生效；如果返回错误或超时，说明记录还没生效（通常 5 分钟到几小时，也可能更久）。

网站部署到 GitHub Pages 需要几步？

网站部署到 GitHub Pages 需要四步：创建公开仓库、在仓库设置里开启 Pages 功能、把网站文件推送到仓库、配置自定义域名。整个过程免费，且不需要国内服务器备案，是个人博客和静态站的首选。

本次案例的网站是手写的纯静态 HTML，包含首页 index.html、文章页、robots.txt 和 sitemap.xml 四个文件。部署时还要注意 robots.txt 要放行所有爬虫——如果是做 GEO（生成式引擎优化），被 AI 引擎引用是核心目标，没有任何理由屏蔽 GPTBot、ClaudeBot、Baiduspider 等爬虫。

部署完成后，先不要急着提交百度，先用浏览器或 curl 确认 https://www.jiyou.site 能正常打开，再进入下一步。因为百度只会收录能稳定访问的页面，一个经常打不开的网站会被降权。

为什么配置好域名后 HTTPS 一直不生效？

配置好域名后 HTTPS 不生效，最常见的原因是证书签发需要时间：GitHub Pages 使用 Let's Encrypt 自动签发证书，域名配置变更后需要 24-48 小时才会生效，期间访问会提示不安全或直接打不开，这属于正常等待，不是配置错误。

本次案例中，网站刚上线一天时输入域名访问显示证书未生效，排查后发现 DNS 解析完全正常，问题就出在证书签发延迟上。另一个容易误判的点是：如果主域名能访问而 www 子域名不能访问，要先检查 DNS 的 www 记录是否存在、是否和 GitHub 配置的域名一致，而不是怀疑 HTTPS。两者排查顺序应该是：先 DNS，再 GitHub 配置，最后等证书。

百度搜索资源平台怎么添加和验证站点？

在百度搜索资源平台添加站点，需要经过三步：注册登录平台、添加站点并输入完整域名、选择验证方式证明网站归你所有。验证通过后，这个站点才进入百度的可管理列表，可以提交 sitemap 和查看数据。

验证方式有两种：文件验证和 HTML 标签验证。文件验证是把百度提供的验证文件下载后上传到网站根目录，HTML 标签验证是在首页 head 里加一段 meta 标签。对于 GitHub Pages 这类静态站，推荐用文件验证——把验证文件放进仓库根目录推送即可，比改首页 HTML 更干净，也方便以后移除。

添加站点时填写的域名要与网站实际访问地址一致。本次案例中网站以 www.jiyou.site 为主域名，就在平台填 www.jiyou.site，而不是填不带 www 的主域名，否则验证时容易对不上。

为什么提交 sitemap 时显示"今日提交上限0条"？

提交 sitemap 时显示"今日提交上限0条、今日提交余额0条"，是百度对新站点的配额限制，不是平台出错。新添加的站点需要先被百度确认有效，才会逐步开放 sitemap 提交权限，通常要等站点验证通过并稳定运行一段时间。

遇到这个提示不要反复重试，正确的做法是先用"普通收录"里的手动 URL 提交方式，把首页和几个核心文章的网址逐条提交，每天都可提交少量（新站通常有几十条的日配额）。手动提交的 URL 会进入百度的优先抓取队列，效果与 sitemap 相当。同时保持网站稳定可访问、持续更新内容，等配额开放后再补交 sitemap。

网站提交后多久能被百度收录？

网站提交后，百度收录时间通常在一周到一个月之间，具体取决于网站质量、内容更新频率和外部引用情况，新网站首次收录偏慢，持续更新后抓取频率会提升。提交只加速被发现的进程，不能保证收录结果。

判断是否被收录的方法是：在百度搜索框输入 site:你的域名，如果有结果返回，说明已被收录。如果一个月后还没有收录，依次检查：robots.txt 是否误拦了 Baiduspider、网站是否经常打不开、内容是否与站内已有内容重复。最后提醒一点：百度收录是后续所有工作的前提，但不要干等——继续写高质量、结构清晰的文章，网站内容越丰富，被收录和被 AI 引擎引用的概率越大。
